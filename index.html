¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje que controla la apariencia de las páginas web: colores, tipografías, espacios y la disposición de los elementos. Mientras HTML define la estructura, CSS se encarga de que todo se vea bien en cualquier dispositivo.

¿Qué aprenderé en este curso?

Aprenderás el modelo de caja, Flexbox, Grid, propiedades personalizadas, posicionamiento, transiciones y animaciones, además de cómo crear diseños responsivos. Todo con ejercicios y proyectos prácticos.

¿Qué es CSS GRID?

CSS Grid es un sistema de diseño en dos dimensiones, filas y columnas, que permite crear estructuras de página complejas de forma sencilla, sin depender de trucos con floats o posicionamiento.
